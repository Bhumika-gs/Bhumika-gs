## Loan Approval Prediction

A machine learning project that predicts whether a loan application is likely to be approved based on applicant information.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest
- Streamlit
- Matplotlib
- Seaborn

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Streamlit Deployment

## Machine Learning Model

Random Forest Classifier was used to predict loan approval.

## Dataset 
Download dataset from Kaggle
https://www.kaggle.com/datasets/ninzaami/loan-predication?resource=download
